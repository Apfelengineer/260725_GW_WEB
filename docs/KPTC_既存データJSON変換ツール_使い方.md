# 既存データJSON変換ツール

## 起動

`02_release/converter/KPTC_既存データJSON変換ツール.html`をPCへ保存し、EdgeやChromeで開きます。**このHTMLファイル1個だけで動作します。** インターネット接続、サーバー、PHP、Python、Nodeのインストールは不要です。スケジューラへ配置する必要もありません。

このチャットのプレビューで開けない場合は、保存したファイルをPCのブラウザで直接開いてください。

## 操作

1. 「フォルダをまとめて選択」で、ユーザー別データの親フォルダを選びます。ブラウザのフォルダ確認が出た場合は、対象を確認して選択します。1人分の複数月だけなら「ファイルをまとめて選択」でschとdtlを選べます。選び直すと入力を置き換えます。
2. 元フォルダごとに、KPTCの登録先ユーザーを指定します。指定するのは電気通信係`e001`、試験室`t001`などの**内部ユーザーID**であり、社内入口の3桁IDではありません。KPTCのJSON取込画面でも確認できます。旧版の`m1`等から移行した場合は、最新版のユーザー一覧で確認してください。
3. 必要ならKPTCバックアップJSONを参照用に読み込みます。ユーザーIDと名前・予定種別を一覧から選べ、存在も照合できます。バックアップのパスワード・アカウント情報は変換に使用しません。
4. 旧分類からKPTCの予定種別名への対応を設定します。例えば「お客様相談室」を、移行方針に応じて「その他」などへ対応付けます。未登録の種別を使う場合は、先にKPTC側へ追加してください。
5. メモのカンマ区切りを確認します。既定ではカンマを保持し、元の複数行メモだったことが確認できた場合だけ「改行へ変換」を選びます。引用符で囲まれたカンマは本文として扱います。
6. 「JSONへ変換して内容を確認」を押します。エラーがあれば予定JSONは出力しません。レポートで該当ファイル・行位置・原因を確認します。
7. 日付・終日・複数日・分類・場所・メモを確認し、「予定JSONを保存」と「確認レポートを保存」を押します。JSONが分割された場合は全ファイルを保存してください。
8. KPTC側のDBをバックアップしたうえで、管理者モードの「JSONから予定を取込」からJSONを番号順に取り込みます。この変換ツールがスケジューラへ送信・登録することはありません。

## 変換規則

- CP932の元バイトを固定位置で分離してから日本語へ変換します。元ファイルは変更しません。
- `YYYYMM.sch`と同じフォルダの`YYYYMM.dtl`を組み合わせます。時刻が両方空欄なら終日（00:00〜23:59）、113〜114バイトの期間は開始日を含む日数です。月末・年末も計算します。
- 26〜29バイトの表示・通知コードと115〜128バイトの色コードは無視します。場所は`location`、詳細メモは`memo`へ保存します。非公開指定は`false`です。
- 期間省略は単日です。期間`00`は既定ではエラーとし、画面で明示的に指定した場合だけ単日へ変換し、警告を記録します。
- 部分的な時刻空欄、不正日付・期間、欠落した参照メモ、重複したファイルなどはエラーとし、出力を止めます。dtlだけでは変換できません。
- 1回の入力上限は1000ファイル・合計50MiB、変換する予定は100000件までです。出力はKPTC取込上限の1MiB・5000件以下へ自動分割します。
- 元の行位置・年月・登録先ユーザーから固定IDを作ります。同じファイル・同じユーザー指定での再変換は同じIDになります。フォルダの表示名はID生成に使用しません。元ファイルの行順変更や、別のユーザーへの割当変更後の再取込は、重複・競合に注意してください。
- 同じ内容の予定は警告しますが削除しません。月またぎの予定が翌月にも収録される場合の実データ規則は未確認のため、移行前に確認してください。

## セキュリティ・保存

外部ライブラリ、外部通信、サーバーへのアップロード、ブラウザへの永続保存はありません。画面の「ファイル選択」はPC内でファイルを読む操作です。読込データはツールを閉じるとメモリから失われます。保存したJSONやレポート、ブラウザのダウンロード履歴は別途PCに残ります。

JSON・レポート・参照用バックアップは非公開情報です。GitHubやWeb公開フォルダへ置かないでください。KPTCの公開カレンダー用JSONとは異なります。

## 開発者向け

ソースは`01_source/tools/legacy-converter/`です。`pnpm run build:converter`で単体HTMLへまとめ、`pnpm run test:converter`で変換・画面処理・取込互換性を検証します。通常の`pnpm run build`でも配布物を再生成します。

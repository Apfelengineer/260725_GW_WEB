# さくらサーバー実行ファイル・スナップショット

2026年9月1日にソースから再ビルドし、さくらインターネットへ配置したKPTC Schedulerの実行用ファイルです。`schedule/`と`calendar/`は、それぞれ同日に配備した`dist-internal/`と`dist-public/`の内容に対応します。

## フォルダ構成

- `schedule/`: 内部スケジューラー用。サーバー上の `/home/apfelrunner/www/GW/schedule/` に対応します。
- `calendar/`: 外部公開する試験室空き状況用。サーバー上の `/home/apfelrunner/www/GW/calendar/` に対応します。
- `SHA256SUMS`: サーバー上の各ファイルと内容が一致することを確認するためのSHA-256一覧です。

保存している実行ファイルは合計29ファイルです。m6・m7・m8の試験室画像と、公開対象を安全に追加する設定ファイルを含み、全ファイルについて配備後のサーバー側とこのフォルダ側のSHA-256が一致することを確認しています。

## ソースコードとの違い

GitHubのルートにある`.tsx`・`.ts`は開発用ソースです。Viteによるビルド後は、ブラウザーが実行できる`.html`・`.js`・`.css`へ変換されます。このフォルダはビルド後にサーバーへ配置された完成物なので、`.tsx`は含まれません。PHPはサーバーが直接実行するため、`.php`のまま含まれます。

## 意図的に含めていないもの

次のデータはサーバーのWeb公開ディレクトリ外にあり、機密情報を含むため、このフォルダおよびGitHubには保存していません。

- SQLiteデータベースとパスワードハッシュ
- 内部・外部連携の共有秘密鍵
- `internal-env.php`、`public-env.php`などの実環境設定
- 公開用の最新JSONデータ
- セッション、ログ、バックアップ

`.user.ini`は取得時のまま保存していますが、内容は公開領域外の設定ファイルへのパスだけです。秘密値そのものは含みません。

## 利用上の注意

このフォルダだけを別サーバーへコピーしても、データベース、秘密設定、PHP実行環境、Webサーバー設定がないため完全には動作しません。別サーバーへ展開する場合は、`docs/KPTC_Scheduler_独立Linuxサーバー構築・移行手順書.pdf`に従って設定してください。

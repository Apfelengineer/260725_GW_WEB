# Group Watcher WEB

Group Watcher 3.65 の主要機能を、PC・タブレット・スマートフォンから利用できるよう再設計したWEBブラウザ版です。

現在はUI確認用のデモデータで動作します。API仕様の確定後は `app/lib/group-watcher-api.ts` のデータ取得処理をHTTP通信へ置き換えることで、画面側を大きく変更せず接続できます。

デモ版で編集したユーザー・予定・予定種別は、利用中のブラウザ内に保存されます。別端末・別ブラウザとの共有や同時編集は、API・データベース接続後に有効になります。

## 実装済み

- 日・週・月のスケジュール表示切替と前後期間への移動
- 月曜始まり・土日を含む7日間の週表示
- グループ／メンバーの絞り込みと検索
- 予定の新規登録、全ユーザーの予定編集・削除、メモ、非公開設定
- 日付欄のダブルクリック登録と、ドラッグ＆ドロップによる日付・ユーザー間の移動
- 右クリックメニュー（コピー・切り取り・削除）とキーボード操作（Ctrl/Cmd+C、Ctrl/Cmd+V、Delete）
- 行き先・在席状況の一覧と更新
- 個人／グループ／全員宛のメッセージ・伝言メモ
- ユーザーと予定種別の追加・編集・削除
- デモ編集内容のブラウザ内保存
- PC／スマートフォン対応のレスポンシブ表示
- Open Graph共有画像と日本語メタ情報

## 開発

Node.js 22.13以上と pnpm を使用します。

```bash
pnpm install
pnpm run dev
```

検証用ビルド:

```bash
pnpm run build
pnpm test
```

さくらのレンタルサーバー向け静的ビルド:

```bash
pnpm run build:sakura
```

生成された `dist-sakura` の中身をWeb公開フォルダへ配置します。画像やスクリプトは相対パスで出力されるため、初期ドメイン直下でも `/GW/` のようなサブフォルダでも利用できます。

## API接続予定箇所

`app/lib/group-watcher-api.ts` に、メンバー・予定・メッセージの型とデモデータ、APIの差し替え口をまとめています。

想定する主なAPI:

- 認証・ログイン
- グループ／メンバー取得、権限取得
- 予定の一覧・登録・編集・削除
- 在席状況／行き先の取得・更新
- メッセージ／伝言メモの送受信、既読更新
- 祝日・休日・記念日設定
- アラーム／通知設定

## さくらインターネットへの配置

配置方式は契約プランとAPI方式に合わせて確定します。

- VPS／クラウドでNode.jsを稼働できる場合: 現行構成のサーバー出力を利用
- レンタルサーバーで静的ファイル＋PHPを使う場合: フロントエンドを静的出力へ切り替え、APIをPHPで実装

ドメイン、サーバープラン、PHP／Node.jsの利用可否、データベース種別、API仕様をご共有いただいた段階で、本番配置用の設定を追加します。
